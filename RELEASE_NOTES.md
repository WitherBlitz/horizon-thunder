Initial Horizon Thunder modpack, starting with JJThunder To The Max 0.9.0.

- Import the `.mrpack` through Horizon Launcher's Modpacks page, then click
  **Port 1 mods**. Wait for **1 data pack for new worlds** before playing.
- Use the current Horizon Nightly and create a new world in this pack's profile.
- Horizon downloads JJThunder from its official Modrinth CDN and converts it to 26.3.
- Includes a SHA-256 checksum; no original or converted JJThunder data is redistributed.

Validated on Windows with launcher 0.2.63 and game nightly-2026-11-13-9f42064:
zero conversion warnings, 49 loaded chunks, zero pending chunks or chunk decode
errors, and a successful block placement at Y=1000 in a scratch world.
Full Java terrain parity is not yet verified.
